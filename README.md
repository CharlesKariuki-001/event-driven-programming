## The Main Idea

An event driven application does not simply execute everything from top to bottom.

Instead, it waits for something to happen.

For example:

```text
Application starts
       ↓
Form appears
       ↓
Program waits
       ↓
User clicks Button
       ↓
Click event occurs
       ↓
Event handler runs
       ↓
Label text changes
       ↓
Program waits again
